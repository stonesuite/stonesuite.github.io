# STONE — coque PWA (site statique)

Généré par `STONE_PWA/site-build.mjs` — ne pas éditer à la main.
- `/` : coque publique — les univers fermés au lancement y restent fermés
- `/tout/` : même coque, tous les univers ouverts
- `/invest/` : coque STONE qui n'ouvre qu'Invest (lien à donner à un ami ; cible de l'application Android)
- `/invest-next/` : même coque Invest seul, sur le prochain moteur (adresse posée par `tools/next-url.mjs`)
- `/perso/` : coque personnelle (moteurs à configurer sur l'appareil)
- `/.well-known/assetlinks.json` : Digital Asset Links de l'application Android (empreinte Play à poser)
